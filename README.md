# Stead Shopping — Original App Starter

এটি একটি আসল Android marketplace app-এর source starter + backend API।

## Android
Android Studio-তে project root খুলুন এবং Run চাপুন।
Application ID: `com.steadshopping.app`

বর্তমান customer features:
- Home / category
- Search field UI
- Product listing
- Cart
- Checkout
- Customer name / phone / address
- Cash on Delivery
- Orders / tracking status UI
- Account UI

## Backend
`backend` folder:
1. Node.js install
2. `npm install`
3. `npm start`

API:
GET /api/products
POST /api/products
POST /api/orders
GET /api/orders
PATCH /api/orders/:id

## Production-এর জন্য বাকি কাজ
- Real login/OTP
- Real product images + CDN/storage
- Seller registration/panel
- Admin dashboard
- Product CRUD
- Order database connected to Android
- bKash/Nagad/Card payment gateway credentials
- COD settlement
- Delivery/rider/hub management
- Push notifications
- Maps/address selection
- Privacy policy, terms, support
- Play Store signing/release
